# 随心记 · 功能设计

个人使用、免登录的单用户空间；DeepAgents + DeepSeek；每轮回复前用 Jev 识别话题。公网部署需额外设置访问控制。

## 聊天与分类

- 会话与消息持久保存，支持流式回复、停止、失败重试、重命名和删除会话。
- 分类依据最新用户消息和近期上下文，每个现有话题独立使用 Jev Noul 判断，可关联最多三个话题。
- 读取旧记忆与写入新事实分别判断：回忆请求可以按领域检索，新事实归属需要明确实体或本会话上下文。
- 关联概率 >= 0.80 时读取该话题记忆；实际信息录入没有匹配且新话题概率 >= 0.85 时由 DeepSeek 命名，创建或复用同名分类。
- 纯提问、关键词检索、提示已有记忆存在或提供检索名称、问候使用 chat 路由，不创建分类，不进入待归类，也不创建记忆整理任务；相关旧记忆仍可检索。
- 实际信息录入包括事实、偏好、决定、日程、菜谱及知识笔记；消息同时含事实与提问时仍整理实际信息。通用个人信息和稳定偏好使用通用记忆。
- Jev 判断无新信息的概率足够高时直接走 chat；判断不确定或服务不可用时由 DeepSeek 复核信息录入意图。确认无新信息后移出待归类，确认有信息但归属未确定或复核不可用时保留 pending，不强行分类。
- 后续聊天完成时重新排队本会话待处理内容，结合新上下文回溯；后文明确澄清时先由 DeepSeek 补全旧消息，再经原文证据和 Jev 忠实度核验后重新分类，原始消息保持不变。也可手动指定分类或重试。
- 分类阈值属于第一版初始配置，需根据真实使用逐步校准。

## 记忆

- global：本人信息、稳定偏好和回复习惯。topic：项目、计划、决定和进展。
- 每次检索读取通用记忆及匹配话题的相关事实，按预算截断，不读取整库所有话题正文。
- 原始聊天和长期记忆分离。用户事实经 DeepSeek 提取、原文证据检查、Jev 支持度核验后落库。
- 不将助手说法、假设、引用他人或推测直接作为用户事实；记忆只能作为背景数据，不作为系统指令。
- 语义键用于更新与去重，来源消息及记忆变更事件保留；人工可编辑/删除/转移记忆、维护和合并分类。
- 删除会话保留长期记忆，并清空来源消息引用；删除记忆需在记忆页面单独操作。
- 整理任务持久化，重启恢复 running 任务，失败任务可重试。无新上下文时不无限重试 pending。
- 第一版使用语义键和模型提取进行去重，尚无向量检索和自动分类合并。

## 部署与隐私

使用 SQLite WAL + systemd，可在个人服务器上运行，无需额外数据库服务。

- 后端默认监听 `127.0.0.1:8025`，由 Nginx 提供同源路径代理。
- 保留 `self-agent.service` 和 `/opt/self-agent` 作为现有部署标识。
- 模型凭据由服务端 `.env` 或私密文件读取，不放入前端或移动安装包。
- 当前免登录，无多用户隔离；自定义请求头仅用于请求校验，不能替代身份认证。
- 外部模型与判断服务会处理相关文本；请按自身隐私需求选择服务商。
- 原始聊天、记忆库、签名证书、调试截图及备份均不得包含在公开源码中。
- `scripts/deploy.sh` 依赖原环境目录和 Nginx 结构，需要按自己的环境调整。
