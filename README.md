# 随心记

<img src="mobile/static/brand/app-icon.png" width="96" height="96" alt="随心记 Logo">

**随心聊，轻松记。**

**通过聊天记录生活，自动整理，在需要时找回。**

随心记是一个以聊天为入口的个人生活记录工具。随口说下的计划、喜欢的口味、试过的菜谱，或一件想留住的小事，都可以从对话中慢慢积累成记忆。你可以继续聊，也可以在需要时问一句，找回曾经记录的内容。

当前版本：**0.2.5** · [更新记录](CHANGELOG.md)

## 产品特点

### 从一句话开始记录

不用先选笔记本、想标题或整理格式。像平时聊天一样，告诉随心记你的想法、近况和偏好。支持流式回复、停止生成、失败重试，以及历史对话的继续、重命名和删除。

### 让零散信息慢慢有条理

系统识别用户明确提供的事实、偏好、决定、计划、菜谱和知识笔记，整理为通用记忆或话题记忆。纯提问、问候和关键词查询不会被当作新事实保存；归属不明确的内容先进入待归类，等待后续对话澄清，也可以手动选择分类。

### 需要的时候，再找回来

聊天时结合通用记忆和相关话题补充背景，减少重复解释。记忆页支持关键词搜索、按分类查看和来源追溯，让过去聊过的重要信息更容易找到。

### 记忆由你掌握

支持手动添加、修改、删除和转移记忆，以及创建、编辑、合并分类。原始对话与整理后的记忆分别保存；删除对话会保留已整理的长期记忆，若需删除记忆，请在记忆页单独操作。

### Web 与手机端

Web 适配桌面和手机屏幕；手机端使用 uni-app x，当前维护鸿蒙端。支持 Markdown 内容展示，包括列表、引用、代码和表格。手机 App 连接同一个后端时，可访问同一份对话与记忆。

### 可以自行部署

后端使用 SQLite 保存数据，无需额外搭建数据库服务。源码、数据和模型配置分离，便于个人维护、备份和迁移。

## 可以这样用

以下为使用示例，并非真实用户记录；整理与召回效果取决于上下文及模型服务。

| 场景 | 随口记录 | 之后找回 |
| --- | --- | --- |
| 饮食偏好 | “我喜欢清淡一点，做菜少放辣。” | “结合我的口味，想想今晚吃什么。” |
| 日常计划 | “周六准备去图书馆，顺便还书。” | “我之前说周六准备做什么？” |
| 菜谱笔记 | “这次炖豆角先炒肉，再加水焖，最后放土豆。” | “之前记的豆角做法是什么？” |
| 学习进展 | “Vue 的基础部分看完了，接下来学状态管理。” | “我上次学到哪儿了？” |

## 工作方式

```text
随心聊 → 判断是否有值得记录的信息 → 整理为通用 / 话题记忆
                                      ↓
                            不确定时等待澄清或手动归类
                                      ↓
                       继续聊天时召回，或在记忆页查看与编辑
```

记忆整理在后台进行，任务可持久化、失败后重试。系统会检查原文证据，尽量避免把助手回复、假设或推测当作用户事实；模型判断仍可能出错，重要内容请核对原文。

## 技术组成

| 部分 | 技术 |
| --- | --- |
| Web | Vue 3、TypeScript、Vite |
| 手机端 | uni-app x、UTS、原生 Markdown 展示 |
| 后端 | Python 3.12+、FastAPI、SSE |
| 对话与信息提取 | DeepAgents、DeepSeek 兼容接口 |
| 话题判断与记忆核验 | Jev / TypeSafe，结合规则与模型复核 |
| 数据存储 | SQLite，原始对话与长期记忆分离 |
| 部署 | Uvicorn、systemd、Nginx |

产品名称为“随心记”；代码包 `self_agent`、现有 `/self-agent/` 路径及服务名暂时保留，方便已有环境继续使用。

## 本地运行

准备 Python 3.12+、uv、Node.js 22+ 和 npm。模型调用需要自行配置服务商凭据，可能产生费用。

```sh
uv sync --frozen
cp .env.example .env
```

编辑本地 `.env`，填写 `DEEPSEEK_API_KEY`。模型名称填写你的服务商实际支持的名称；默认配置不代表账号一定有访问权限。`.env` 不应提交至 Git。

`.env.example` 默认按本地开发填写：后端接口位于 `/api`，Web 开发服务会将 `/self-agent/api` 代理到后端。

```sh
# 终端一：启动后端
PYTHONPATH=backend uv run --frozen uvicorn self_agent.app:create_app --factory --host 127.0.0.1 --port 8025

# 终端二：启动 Web
npm ci --prefix frontend
npm run dev --prefix frontend
```

浏览器打开 <http://127.0.0.1:5173/self-agent/>。

Jev 使用独立的服务商配置。可通过 `JEV_ENV_FILE` 指向本地私密配置文件，或沿用 `~/.config/jev/.env`。Jev 不可用时部分流程有模型复核或关键词兜底，但不等于完整分类与核验能力可用。

已有 CC Switch 用户也可以用 `uv run --frozen python scripts/configure.py` 从本机配置导入 DeepSeek 凭据；常规安装不依赖 CC Switch。

手机端开发见 [mobile/README.md](mobile/README.md)，功能规则见 [docs/design.md](docs/design.md)。

## 数据与访问边界

- **当前版本为免登录的单用户共享空间，没有账号隔离。** 知道服务地址的人可能读写同一份对话和记忆。自部署时请限制到本机、可信网络，或在反向代理层增加认证，再考虑公网使用。现存密码相关配置用于历史兼容，不代表已启用访问保护。
- 对话和记忆保存在部署环境的 SQLite 数据库中；相关聊天内容会发送给配置的外部模型与判断服务处理，并非完全离线运行。
- 保存日程或提醒偏好不等于创建定时任务，当前不会据此主动发送通知。
- 当前不提供向量检索、自动分类合并或多用户账号系统；分类合并需要手动操作。
- 运行中的 SQLite 请使用在线备份接口，避免遗漏 WAL 数据；数据库和备份均不得上传到公开仓库。

## 发布到 GitHub

仓库仅应包含源码、文档和空值配置示例。`.gitignore` 已排除 `.env`、凭据目录、签名证书与私钥、数据库、调试截图、依赖和构建产物。忽略规则不适用于已经被 Git 跟踪过的文件，也不会保护手动上传的任意文件。

可以生成经过检查的公开源码压缩包：

```sh
python3 scripts/export-public.py
```

脚本按 `.gitignore` 筛选文件，检测常见密钥格式以及本机已知的密钥值，并在导出副本中替换此项目的私人部署域名、IP、移动应用标识和分发链接。输出为 `dist/suixinji-source.zip`，不会包含本地聊天、证书或真实配置。自动扫描不能覆盖所有类型的敏感信息，上传前仍应检查最终文件清单。

不要将真实 Key 写入 Web / App 源码、`VITE_*` 变量、截图、日志、Issue 或 README。若凭据曾进入公开仓库，应先在服务商处撤销并更换，删除当前文件不能消除历史泄露。

现有 `scripts/deploy.sh` 属于原部署环境的运维脚本，涉及服务、Nginx 和证书路径；请按自己的服务器调整后使用。
